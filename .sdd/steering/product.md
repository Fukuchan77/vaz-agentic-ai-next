# Product

この文書は、機能一覧ではなく、製品判断に使う継続的なプロダクト知識を記録する。

## Purpose

VAZ-Agentic-AI-Next は、生成 AI のチャット、検索拡張生成、ツール実行、承認付き長時間ジョブを、
Web UI、バックグラウンドワーカー、Python エージェント API の一貫した境界で提供する統合ハブである。
目的は、LLM デモを増やすことではなく、型、安全性、監査可能性、評価可能性を備えた本番向けの
エージェント基盤を示し、継続的に改善できる状態に保つことである。

## Users & Value

| User / persona | Need | Value delivered |
|---|---|---|
| 認証済み利用者 | 会話、文書検索、承認付きツールを安全に利用したい | ストリーミング UI、引用、HITL、ジョブ進捗を単一の体験で提供する |
| 管理者・運用者 | 誰が何を実行したか把握し、障害や費用を制御したい | RBAC、監査記録、相関 ID、予算、評価レーンを提供する |
| 開発者・検証者 | 新しいモデルやエージェント手法を本番境界の中で検証したい | 型付き契約、差し替え可能な依存、Hermetic test、段階ゲートを提供する |

## Core Capabilities

- **マルチプロバイダ会話** — Anthropic、OpenAI、Ollama を同じサーバ境界から選択し、
  モデル ID と認証情報をクライアントへ露出しない。
- **RAG と出典提示** — pgvector を使った検索結果を不信データとして隔離し、回答に引用を付ける。
- **安全なツール実行** — 破壊的操作を HITL、許可リスト、監査フックの独立した防御で制御する。
- **耐久ジョブ** — Inngest ワーカーが計画を段階実行し、承認待ち、再開、イベント履歴を扱う。
- **独立 Python レーン** — 文書解析・評価サイドカーと FastAPI エージェント API を、
  TypeScript ハブと契約スナップショットで結合する。
- **継続評価** — 決定論的テストと LLM eval を分離し、通常 CI を外部モデルから独立させる。

## Product Principles

- **安全性を機能より先に置く**: 認証、入力検証、承認、監査のない新しい実行経路を増やさない。
- **単一経路へ合流させる**: UI、worker、sidecar ごとに別のポリシー実装を複製せず、共通契約へ流す。
- **プライバシーを既定値にする**: 生のプロンプト、ツール引数、ツール出力を通常ログへ書かない。
- **本番ハブとベータ検証を分離する**: 未確定の大規模更新は兄弟リポジトリで検証し、
  証拠と撤去条件を伴って取り込む。
- **実測で採否を決める**: 性能、コスト、依存更新、マルチエージェント化は測定結果で正当化する。

## Success Signals

- `mise run check` と対象 Python レーンの gate が再現可能に成功する。
- 承認、監査、契約 drift、モデル ID、バンドルサイズの回帰が機械的に検出される。
- 新しい能力が既存の認証・依存注入・型境界・テスト層を迂回しない。
- ベータ検証結果に、採用判断、互換性、再検討条件が記録される。

## Out of Scope

- 汎用のノーコード AI エージェントビルダーや、任意コードを無制限に実行する環境。
- 教材本文の複製。学習パスは兄弟リポジトリ、ここでは本番実装と運用規律を正本とする。
- 十分な再利用需要がない段階での MCP サーバ化や P2P swarm 化。
- Unit / Integration test からの実 LLM、外部ネットワーク、共有本番データへの依存。
